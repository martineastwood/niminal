## Size and contrast

**Cmd/Ctrl+=** and **Cmd/Ctrl+−** make the whole interface larger or smaller, in steps from 85% to 200%, and **Cmd/Ctrl+0** returns to actual size. The footer has the same as **A−** / **A+**, with the current size between them (click it for actual size). While the cursor is in the code editor the same keys change only the code font; **View → Larger Code Font** and **Smaller Code Font** do it from anywhere.

**View → High Contrast** (or the palette) brightens text and borders. The size, code font, contrast and the bar settings below are remembered between sessions.

## Bars

- **Cmd/Ctrl+\\** or the **◧** button in the footer hides and shows the sequence bar.
- **Cmd/Ctrl+Shift+B** or **◨** hides and shows the right bar (project instruments and the sound browser). **Cmd/Ctrl+B** still opens the sound browser, showing the bar if it was hidden.
- Drag the edge beside a bar to size it, or focus the edge with Tab and use **←** / **→** (Shift for bigger steps). Double-click an edge for the default width.
- **Cmd/Ctrl+Shift+F** is focus mode: only the toolbar and the grid. Press it again to come back.

## Keyboard

- **Cmd/Ctrl+K** (or Cmd/Ctrl+Shift+P) opens the command palette. Type any part of an action's name, use **↑** / **↓** and **Enter**. Each action shows its key, if it has one.
- **Cmd/Ctrl+/** or **F1** lists the keys by area.
- **Ctrl+1 … 5** jump to the grid, the sequence, the project instruments, the sound browser and the code. A hidden bar is shown first.
- **F5** plays the song from the selected step, **F8** stops, **Esc** turns record mode on and off.
- **Esc** also puts the cursor back in the grid, and so does a click on a button or a menu choice in the toolbar, the sequence bar or the footer, so the keyboard stays with the cell you were on. Buttons that open something you type into (the command palette, the sound browser, the code editor) keep the focus there instead, and Esc inside the code editor leaves the cursor where it is.
