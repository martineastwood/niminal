## Install

You need a recent [Rust toolchain](https://rustup.rs/).

From a clone of the [repo](https://github.com/martineastwood/niminal):

```sh
cargo install --path crates/niminal-cli   # niminal
cargo install --path sequencer/nimlive    # nimlive
```

Or install from GitHub without cloning:

```sh
cargo install --git https://github.com/martineastwood/niminal niminal-cli
cargo install --git https://github.com/martineastwood/niminal nimlive
```

Check them:

```sh
niminal --version
nimlive --version
```

## Hear something

Save this as `saw_lead.nml` (or use `examples/saw_lead.nml` in the repo):

<Example file="saw_lead.nml" />

Render it to a WAV file:

```sh
nimlive render saw_lead.nml --out saw_lead.wav
```

Open the `.nml` file: tempo, an instrument with units (`hz`, `db`, `ms`), an envelope, and notes timed with `at`.

More examples live under `examples/` — kits and grids (`drums.nml`, `breakbeat.nml`), scenes (`groove.nml`), buses (`room.nml`), and arrangements (`song.nml`).

## Live coding in an editor

The [VS Code / Cursor extension](/reference/editor/) is the main way to live-code: highlighting, diagnostics while you type, and evaluate-while-playing.

```sh
cd editors/vscode && npm install && node install.js   # --cursor for Cursor
```

Reload the window. Start the audio server — **niminal: Start Server in a Terminal** in the command palette, or `niminal server` in a terminal — then open a `.nml` file and press **Cmd+Enter** (macOS) or **Ctrl+Enter** to evaluate the block around the cursor. The status bar shows the bar and tempo, and the sidebar lists scenes and parts. The language server (`nimlive lsp`) works without a server for hover, completion, and errors.

## Live coding from a terminal

The same live sequencer, as its own process, with a REPL and one-shot sends:

```sh
niminal server
# in another terminal:
nimlive live examples/groove.nml
nimlive repl
# in another terminal:
nimlive send 'chorus.start' --quantize "next 4bars"
```

See [Live coding](/guide/live-coding/) for quantization, MIDI, and session replay.
