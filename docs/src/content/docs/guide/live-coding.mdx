---
title: Live coding
description: Run the daemon and send code to it.
---

Start the daemon, then send code to it from the REPL, the CLI or the [VS Code extension](/reference/editor/). Syntax help and completion come from [`niminal lsp`](/reference/editor/) and work without a daemon.

```sh
niminal daemon examples/groove.nml
niminal repl
niminal send 'chorus.start' --quantize "next 4 bars"
```

Every input to a live session is logged by sample (by default under `~/.niminal/sessions/`), so a session replays to identical audio:

```sh
niminal render --replay ~/.niminal/sessions/<log> --out set.wav
```

In the REPL, `:quantize next 4 bars` sets when each statement lands (`:quantize off` clears it); `:quit` exits.
