---
title: nimterm
description: Terminal UI primitives for Nim applications and agent frontends.
---

nimterm provides generic terminal UI primitives for Nim applications and agent
frontends. It includes testable geometry and rendering, widgets, ANSI-aware
text layout, Markdown, and a vocabulary for agent lifecycle events.

nimterm does not depend on nimgent. Applications can adapt any agent or event
source to its UI events; nimlet is the first complete example.

[View nimterm on GitHub](https://github.com/martineastwood/nimterm)
