The **orchestra** is niminal’s DSP and composition language: typed parameters, named arguments, opcodes you can chain, and a score you can also drive from outside.

niminal is in alpha. This reference describes what works today. The [language spec](https://github.com/martineastwood/niminal/blob/main/niminal%20Spec.md) is the longer-term design; where the two disagree, trust the docs and the compiler.

A minimal instrument:

```nml
instr pluck(freq: hz, amp: db = -6db, bright: 0..1 = 0.5) {
  level = env[0 2ms 1 600ms.exp 0]
  osc(saw, freq)
    .lpf(cutoff: freq * (2 + bright * 6), res: 0.3)
    .gain(amp) * level
}
```
