## The stack

Each Niminal project does one job and can be used independently. Together they
cover the path from calling a model to shipping an interactive agent.

<CardGrid stagger={true}>
	<Card title="nimgent" icon="rocket">
		Build provider-native LLM applications and agents with streaming, typed
		tools, structured output, and sessions.
	</Card>
	<Card title="nimterm" icon="seti:terminal">
		Build testable terminal interfaces with widgets, Markdown, agent events,
		and a native POSIX backend.
	</Card>
	<Card title="nimwire" icon="setting">
		Build MCP servers and backends in Nim.
	</Card>
	<Card title="nimlet" icon="pencil">
		See the complete stack in a minimal native coding agent built with nimgent
		and nimterm.
	</Card>
</CardGrid>
