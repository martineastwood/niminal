---
title: Reserved words
description: Names that cannot be used as identifiers in niminal.
---

None of these can be used as a name.

| Kind | Names |
| --- | --- |
| Declarations | `instr`, `mono`, `fn`, `const`, `state`, `bus`, `sample`, `kit`, `ctl`, `track`, `clip`, `scene`, `arrangement`, `config`, `use`, `as`, `with` |
| Performance and score | `start`, `stop`, `play`, `mute`, `unmute`, `solo`, `unsolo`, `undo`, `clear`, `set`, `hush`, `panic`, `reset`, `new`, `capture`, `last`, `tempo`, `meter`, `at`, `for`, `over`, `next`, `now`, `cycle` |
| Control flow | `if`, `else`, `for`, `in`, `reset_on` |
| Logic | `and`, `or`, `not`, `true`, `false` |
| Rates | `const`, `init`, `control` |
| Literal prefixes | `env[...]`, `grid[...]`, `grid { ... }` |
| Units | `num`, `int`, `sec`, `ms`, `samples`, `hz`, `khz`, `db`, `st`, `deg`, `bpm`, `beat`, `beats`, `bar`, `bars`, `%` |
| Implicit names | `out`, `it`, `note` |
| Constants | `pi`, `sample_rate` |
| Universal controls | `pan`, `gain`, `to`, `dur`, `nudge` |
