---
title: Reserved words
description: Names that cannot be used as identifiers in niminal.
---

None of these can be used as a name.

| Kind | Names |
| --- | --- |
| Declarations | `instr`, `mono`, `opcode`, `state`, `bus`, `sample`, `kit`, `ctl`, `track`, `clip`, `scene`, `arrangement`, `config`, `use`, `as`, `with` |
| Performance and score | `start`, `stop`, `play`, `mute`, `unmute`, `solo`, `unsolo`, `undo`, `clear`, `set`, `hush`, `panic`, `reset`, `new`, `tempo`, `meter`, `at`, `for`, `over`, `next`, `now`, `cycle` |
| Control flow | `if`, `else`, `for`, `in` |
| Literal prefixes | `env[...]`, `grid[...]`, `grid { ... }` |
| Units | `sec`, `ms`, `samples`, `hz`, `khz`, `db`, `st`, `deg`, `bpm`, `beat`, `beats`, `bar`, `bars`, `%` |
| Implicit names | `out`, `it` |
| Universal controls | `pan`, `gain`, `to`, `dur`, `nudge` |
