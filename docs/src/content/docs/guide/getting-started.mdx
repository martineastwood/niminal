niminal is in **alpha**. Syntax and behaviour can change; expect rough edges.

## Install

### On a Mac (Apple Silicon, macOS 13+)

Download the dmg from [GitHub Releases](https://github.com/martineastwood/niminal/releases) and drag the **Niminal** folder onto Applications. It holds Tracker, Stage, the `niminal` and `niminal-live` commands, the VS Code extension and the examples. Tracker and Stage start the audio server for you, and offer to put the commands on your PATH the first time they open (or later, with **File > Install Command Line Tools…**).

Or with Homebrew, which also links the commands:

```sh
brew tap martineastwood/niminal
brew trust --cask martineastwood/niminal/niminal   # recent Homebrew only
brew install --cask martineastwood/niminal/niminal
```

The apps are not notarized by Apple. If you used the dmg and macOS blocks one, approve it under **System Settings > Privacy & Security > Open Anyway**. Homebrew clears that warning for you.

### From source

You need a recent [Rust toolchain](https://rustup.rs/).

From a clone of the [repo](https://github.com/martineastwood/niminal):

```sh
cargo install --path crates/niminal-cli   # niminal
cargo install --path sequencer/live-cli    # niminal-live
```

Or install from GitHub without cloning:

```sh
cargo install --git https://github.com/martineastwood/niminal niminal-cli niminal-live-cli
```

Check them:

```sh
niminal --version
niminal-live --version
```

## Hear something

Save this as `saw_lead.nml` (or use `examples/saw_lead.nml` in the repo):

<Example file="saw_lead.nml" />

Render it to a WAV file:

```sh
niminal-live render saw_lead.nml --out saw_lead.wav
```

Open the `.nml` file: tempo, an instrument with units (`hz`, `db`, `ms`), an envelope, and notes timed with `at`.

More examples live under `examples/` — kits and grids (`drums.nml`, `breakbeat.nml`), scenes (`groove.nml`), buses (`room.nml`), and arrangements (`song.nml`).

## Live coding in an editor

The [VS Code / Cursor extension](/reference/editor/) brings live coding to your own editor: highlighting, diagnostics while you type, and evaluate-while-playing. [Stage](/reference/stage/) does the same in a window of its own, with scenes, lanes and meters beside the code.

With the macOS download, choose **File > Install VS Code Extension…** in Tracker or Stage (they also offer it the first time they open). Otherwise, from a clone of the repo:

```sh
cd editors/vscode && npm install && node install.js   # --cursor for Cursor
```

Reload the window and open a `.nml` file and press **Cmd+Enter** (macOS) or **Ctrl+Enter** to evaluate the block around the cursor. The status bar shows the bar and tempo, and the sidebar lists scenes and clips. The extension starts the audio server if none is running, and it stops when the last client closes. The language server (`niminal-live lsp`) works without a server for hover, completion, and errors.

## Live coding from a terminal

The same live sequencer, as its own process, with a REPL and one-shot sends:

```sh
niminal server
# in another terminal:
niminal-live live examples/groove.nml
niminal-live repl
# in another terminal:
niminal-live send 'chorus.start' --quantize "next 4bars"
```

See [Live coding](/guide/live-coding/) for quantization, MIDI, and session replay.

## If something goes wrong

niminal keeps its logs in `~/.niminal/`:

| File | What it holds |
| --- | --- |
| `crash.log` | A panic in `niminal`, with the build and a backtrace |
| `server.log` | What the server printed when an app or the editor started it; `server.log.old` is the run before |
| `sessions/` | A log of each session, newest kept |

If you report a problem, [open an issue](https://github.com/martineastwood/niminal/issues/new?template=bug_report.md) with the version from `niminal --version`, a minimal `.nml` file that shows it, and any of these files.
