The **orchestra** is niminal’s DSP and composition language: typed parameters, named arguments, opcodes you can chain, and a score model any client can write.

A minimal instrument:

```nml
instr pluck(freq: hz, amp: db = -6db, bright: 0..1 = 0.5) {
  level = env[0 2ms 1 600ms.exp 0]
  osc(saw, freq)
    .lpf(cutoff: freq * (2 + bright * 6), res: 0.3, model: ladder)
    .gain(amp) * level
}
```
