niminal is in **alpha**. Syntax and behaviour can change; expect rough edges.

## Install

You need a recent [Rust toolchain](https://rustup.rs/).

From a clone of the [repo](https://github.com/martineastwood/niminal):

```sh
cargo install --path crates/niminal-cli
```

Or install from GitHub without cloning:

```sh
cargo install --git https://github.com/martineastwood/niminal niminal-cli
```

Check it:

```sh
niminal --version
```

## Hear something

Save this as `saw_lead.nml` (or use `examples/saw_lead.nml` in the repo):

<Example file="saw_lead.nml" />

Render it to a WAV file:

```sh
niminal render saw_lead.nml --out saw_lead.wav
```

Open the `.nml` file: tempo, an instrument with units (`hz`, `db`, `ms`), an envelope, and notes timed with `at`.

More examples live under `examples/` — kits and grids (`drums.nml`, `breakbeat.nml`), scenes (`groove.nml`), buses (`room.nml`), and arrangements (`song.nml`).

## Live coding

Start the engine with a file, then send code from the REPL or another terminal:

```sh
niminal daemon examples/groove.nml
niminal repl
# in another terminal:
niminal send 'chorus.start' --quantize "next 4bars"
```

See [Live coding](/guide/live-coding/) for the REPL, quantization, MIDI, and session replay.

## Editor

The [VS Code / Cursor extension](/reference/editor/) adds highlighting, diagnostics, and evaluate-while-playing. Install it from `editors/vscode`, run `niminal daemon`, then evaluate with **Cmd+Enter** (macOS) or **Ctrl+Enter**.

The language server (`niminal lsp`) works without a daemon for hover, completion, and errors.
