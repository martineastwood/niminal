title: Language overview
description: The niminal language — one file, half compiled by the server, half read by the sequencer.
---

A `.nml` file is one language: typed parameters, named arguments, functions and opcodes you can chain, and a score you can also drive from outside.

Two programs read it. **niminal**, the server, compiles instruments, effects and routing into sound. **niminal-live**, the sequencer, adds tempo, clips, scenes and patterns on top, and sends the server notes stamped with a time. Every page below says which of the two runs what it describes.

niminal is in alpha. This reference describes what works today. The [language spec](https://github.com/martineastwood/niminal/blob/main/niminal%20Spec.md) is the longer-term design; where the two disagree, trust the docs and the compiler.

A minimal instrument:

```nml
instr pluck(freq: hz, amp: db = -6db, bright: 0..1 = 0.5) {
  level = env[0 2ms 1 600ms.exp 0]
  osc(saw, freq)
    .lpf(cutoff: freq * (2 + bright * 6), res: 0.3)
    .gain(amp) * level
}
```
