Native AI for Nim

The AI stack for Nim

Streaming models, typed tools, structured output, agents, MCP servers, and terminal interfaces, written in Nim and compiled to small native binaries.

Use nimlet Build with the stack 

import nimgent
import nimgent/providers/openai

let model = openAI(getEnv("OPENAI_API_KEY")).model("gpt-4o-mini")
let response = generateText(
  model,
  system = "You are a concise assistant.",
  prompt = "Explain why the sky is blue in one sentence.")

echo response.text

One typed API across providers. Install a package with nimble install nimgent, nimble install nimwire, or nimble install nimterm.

Coding agent

nimlet changes your project

nimlet is a local coding agent for software projects. Run it in a repository, describe the change you want, and it inspects the files, edits them, runs the commands you approve, and keeps the session for later. It ships as a compiled native binary, so the machine running it needs no language toolchain. nimlet is built on top of the Niminal stack: nimgent for models and tools, nimwire for MCP, and nimterm for the terminal interface.

your-project 
$ nimlet

> Fix the failing parser test and run the focused test.

plan  Inspect the parser and its tests
read  src/parser.nim, tests/parser_test.nim
edit  Apply the smallest safe change
bash  nimble test parser
done  The focused test passes.

  • Quiet while you decide

    It blocks while waiting on you, a provider, or a subprocess. No polls, no timers, no idle CPU.

  • Your provider, your keys

    Requests go straight to the provider you pick. Credentials stay in your environment or in ~/.nimlet/auth.json.

  • Control where it counts

    Reads, searches, and workspace edits run freely. Shell commands and extensions ask the first time, with per-session and per-project grants.

  • Built to be extended

    Add project instructions, skills, prompt templates, external tools, or a persistent extension in any language.

Wired providers: OpenRouter, OpenAI, Anthropic, Gemini, Mistral, Hyper, OpenCode, and ChatGPT-backed Codex through /login. 

$ export OPENROUTER_API_KEY=your-key
$ cd /path/to/your/project
$ nimlet

Libraries

Three Nim packages nimlet is built from

Each library stands on its own. Build an agent, an MCP server your editor can talk to, or a terminal interface for a service you already have.

  • nimgent

    nimble install nimgent

    A Nim SDK for LLM apps and agents. One typed API for generation, streaming, tools, structured output, agents, conversations, retrieval, and MCP clients, with providers you can swap.

    • The same generation code across OpenAI, Anthropic, Gemini, OpenRouter, Mistral, and your own provider
    • Streaming text, typed tools, and structured output
    • Agents, conversations, embeddings, and retrieval

    nimgent.niminal.dev

  • nimwire

    nimble install nimwire

    MCP server primitives for Nim. Declare typed tools, resources, and prompts, then serve them over stdio, Streamable HTTP, or WebSocket.

    • MCP over stdio, Streamable HTTP, and WebSocket
    • Tools, prompts, resources, URI templates, and completion
    • Authorization, deadlines, cancellation, progress, and metrics

    nimwire.niminal.dev

  • nimterm

    nimble install nimterm

    Terminal UI primitives for Nim. A testable canvas, layout, themes, Markdown, widgets, and the lifecycle events an agent transcript needs.

    • Cells, layout, themes, and Markdown rendering
    • Text, panel, input, menu, and question widgets
    • Agent lifecycle events, with POSIX and Windows backends

    nimterm.niminal.dev

nimlet is the application these packages came from, and it declares all three as dependencies. Its model calls, tools, and sessions run through nimgent, and its interactive interface is built with nimterm.
