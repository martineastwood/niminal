Render any `.nml` file to WAV:

```sh
nimlive render examples/saw_lead.nml --out saw_lead.wav
```

## Arrangements

An `arrangement` plays scenes in order. Render it by name, or just a passage of it:

<Example file="song.nml" />

```sh
nimlive render examples/song.nml song --out song.wav
nimlive render examples/song.nml song --from "bar 5" --to "bar 9" --out passage.wav
```

## Live pieces and duration

Files that start clips or scenes and never stop (like `examples/groove.nml` when you strip the timed `hush`) need an end time:

```sh
nimlive render examples/breakbeat.nml --out breakbeat.wav --bars 4
nimlive render piece.nml --out piece.wav --seconds 30
```

A file with a tempo ramp (`tempo … @ next … over …`) is played through a session the same way; say how long with `--bars` or `--seconds`. `--stems` works too; an arrangement name, `--score`, `--from` and `--to` aren't available for that path.

## Stems

`--stems` writes a file for every track and every bus as well as the mix, into the folder given by `--out`:

```sh
nimlive render examples/groove.nml --stems --out stems/
# wrote 5 files into stems/ (33.49s): mix, space.fx, bass, lead, space
```

Each stem is what that track put out after its own effects and before the master stage, so it has no limiter on it. The stems of the tracks that go to the master add up to the mix, and all files are the same length, so they line up in a mixer. A bus's file is the sum of what was sent to it; the channel that processes a bus (`space.fx` for `bus space { … }`) has its own. Parts that play bare instruments with no part of their own are in `direct.wav`.

## External scores

Play events from a `.nms` JSON score on the instruments in a file:

```sh
nimlive render examples/saw_lead.nml --score examples/phi.nms --out phi.wav
```

See [Score model](/reference/score-model/) for the format. Live sessions can also inject events with the daemon's `events.send` method ([protocol](/reference/protocol/)).

## Limiter and replay

Offline renders use a master limiter by default; pass `--no-limiter` to turn it off.

To re-render a live set from its log:

```sh
niminal replay ~/.niminal/sessions/<log> --out set.wav --channels 2
```
